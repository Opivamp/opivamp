- **Leadership**: Peter Oyedemi (*Founder of OPIVAMP GRANTS & Lead Funding Strategist*)

  - **Nonprofit Organizations**: 501(c)(3) charities, community-based organizations, social service agencies, educational and youth programs.

## 🚀 Key Features

1. **Interactive Audience Selector**: Instant tab switching on the homepage for Nonprofits vs. Businesses without page reloads.
2. **Dynamic Readiness Self-Assessment**: Real-time score calculator that diagnoses an organization's grant readiness tier and pre-fills the consultation scheduler.
3. **Interactive Package & Pipeline Estimator**: Live opportunity slider calculating research and proposal fees, with automatic 30% discount logic for 5+ applications.
4. **Cinematic Architectural Hero**: High-contrast, glass skyscraper background with ambient lighting and radiant typography.
5. **Noticeable Button Hover System**: Luminous shimmer wave glint, tactile elevation lift (`translateY(-3px) scale(1.02)`), and dynamic ambient glow on all buttons.
6. **Accessible Navigation**: Categorized dropdown menus with keyboard support (`Tab`, `Escape`) and mobile drawer.
7. **Zero Dependencies**: Built on standard HTML5, CSS3, and modern JavaScript (ES6+). Runs directly in any web browser without build tools.

## 💻 Quick Start & Local Preview

### Option 1: Double-Click
- Double-click `index.html` or `open_site.bat` in Windows Explorer to open directly in your default web browser.

### Option 2: Local HTTP Server
- Double-click `start_server.bat` or run PowerShell:
  ```powershell
  .\serve.ps1 -Port 8080
  ```
- Navigate to `http://localhost:8080` in your browser.
